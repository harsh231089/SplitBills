# Tabby

Open `index.html` in a browser to use the app. No server or account is required.

Create groups, add members and expenses, and record payments. Expenses are split equally among the selected members; remaining cents are distributed in member order. Payments are records only and do not transfer money.

The initial group is an editable example. Delete it from **Manage group** when you no longer need it.

Expenses and payments remain in the group's activity history after they are settled, until you delete the entries or the group. Data is stored in this browser on this device. Clearing browser data or switching browsers can remove access to it. Fonts are downloaded from Google Fonts when available; the app works without them.
